# Real-Time Notification & Messaging Service
**Real-Time Notification & Messaging Service** · Category: Backend (Backend)

> This project is for a specific company/client — the source code is not public.
> Private client work — the source code is not public.

## Overview
SignalR notification service that supports more than 5,000 concurrent connections.

## Highlights
- Redis Backplane for distributed WebSockets
- RabbitMQ for reliable event processing
- 99.9% uptime with Circuit Breaker pattern

## Role
Backend Developer: design and build backend services and APIs, manage databases and caching, implement authentication and security, and optimize performance.

## Technologies
ASP.NET Core, SignalR, WebSockets, Redis Pub/Sub, RabbitMQ, Docker, Prometheus
