# خدمة الإشعارات والرسائل في الوقت الفعلي
**Real-Time Notification & Messaging Service** · التصنيف: خلفية (Backend)

> هذا المشروع خاص بشركة/عميل محدد، والكود المصدري غير منشور.
> Private client work — the source code is not public.

## نبذة عن المشروع
خدمة إشعارات SignalR تدعم أكثر من 5,000 اتصال متزامن.

## أبرز النقاط
- Redis Backplane للـ WebSockets الموزع
- RabbitMQ لمعالجة الأحداث بشكل موثوق
- 99.9% uptime مع نمط Circuit Breaker

## الدور
مطوّر Backend: تصميم وبناء الخدمات الخلفية وواجهات API، وإدارة قواعد البيانات والتخزين المؤقت، وتنفيذ المصادقة والأمان وتحسين الأداء.

## التقنيات المستخدمة
ASP.NET Core, SignalR, WebSockets, Redis Pub/Sub, RabbitMQ, Docker, Prometheus
